# Car Parking Management System

A Car Parking Management System project in C++ that manages parking slots, vehicle entry and exit, and parking records.

## About

This project is a console-based application that helps manage a parking area. It keeps track of available parking slots, records vehicles when they enter and leave, and maintains parking records.

## Features

- Add a vehicle to an available parking slot
- Remove a vehicle when it exits
- View available and occupied slots
- Maintain parking records
- Search for a vehicle by its number

## How to Compile and Run

You need a C++ compiler such as **g++** (MinGW on Windows) installed.

```bash

./parking
```

On Windows Command Prompt, run it with:

```bash
parking.exe
```

You can also open the project in **VS Code**, **Code::Blocks**, or **Visual Studio** and run it from there.
